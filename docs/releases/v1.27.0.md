# Marchine v1.27.0 — Import Games, Keep It Simple

**Game Machinery.** Marchine remains a compact, terminal-native, MAME-first Linux launcher. This release makes the general-purpose **GAMES** source easier to populate and maintain, while refining navigation and readability across the interface.

## Highlights

### Bulk import, without a file browser

- Open **`S` → GAMES → IMPORT GAMES** and enter one exact path, directory, or filename pattern such as `~/.local/share/applications/*.desktop` or `~/Games/*.AppImage`.
- Preview supported native executables, executable scripts, AppImages, and standard Linux `.desktop` launchers in a **scrolling, multi-select playlist**. Selection remains intact as the list scrolls; use `Space`/`Enter` to toggle entries, `A` for all, and `N` for none.
- Duplicate entries are identified before import. Save selected new entries to Marchine's existing local configuration in one operation; there's no account service, library scraping, or background catalog download.
- Standard Linux `.desktop` shortcuts launch through the system's `gio` desktop-launch mechanism. Marchine references the existing shortcut instead of copying or modifying it.

### Safer cleanup and confirmations

- **REMOVE GAME** now offers **Remove All** (`A` or controller Menu), alongside single-entry removal.
- Import and removal confirmations require an explicit **keyboard `Y`**. `Enter` and controller A no longer count as Yes; `N` or `Esc` cancels.
- Only Marchine's saved GAMES entries change. No executables, shortcuts, ROM files, or Arcade settings are deleted.

### More consistent keyboard and controller experience

- **`S` opens Setup** from Info, Credits, and Categories as well as from the library. `Tab` remains intentionally context-sensitive and does not switch sources from secondary screens.
- Shortcut hints use **theme-aware accent-colored keys**, plain action labels, and muted separators. The same visual language now extends across the library, help, setup, import, edit, removal, and confirmation screens.
- New regression tests cover import behavior, removal safeguards, explicit confirmations, navigation, and shortcut presentation.

## Install / Update

Download the Linux amd64 archive and its matching `.sha256` file from this release. Verify the checksum before extracting. The archive contains the `marchine` executable and desktop icons; use the [README](https://github.com/Magik23/Marchine#readme) for the full installation instructions.

Already running Marchine? Your existing `~/.config/marchine/config.toml` and Arcade cache are not replaced by the new import workflow. The source installer preserves an existing configuration.

## Notes

- MAME remains Marchine's automatic Arcade indexing driver; GAMES is a separate, manually configured or path-imported source.
- Imported launch targets must already exist and be runnable on the host. Import does not install games or required launch utilities.
- Local configuration and launcher behavior remain the same basic model as v1.26.0: lightweight, explicit, and offline-friendly.
