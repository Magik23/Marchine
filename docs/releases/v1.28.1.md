# Marchine v1.28.1 — Cleaner Playlists

**Game Machinery.** A focused maintenance release for the playlist browsing experience.

## What changed

- **Cleaner playlist rows.** Removed the repeated `[ARCADE]` / `[GAMES]` suffixes from entries inside playlists. Long game names have more room to breathe.
- **Source details where they belong.** The selected game's right-hand detail panel now shows `SOURCE: ARCADE` or `SOURCE: GAMES`. Arcade metadata remains available there too.
- **Documentation and tests.** Added playlist source-display regression coverage and clarified the README's controller/keyboard reference, including Arcade-only Categories and keyboard-only font reset.

## What didn't change

The three sources—ARCADE, GAMES, and PLAYLISTS—work as before. Playlists retain their saved game identities, ordering, configuration, and launch behavior. There are **no new controller bindings**, no MAME upgrades, and no changes to your ROMs or personal configuration.

## Install / update

Download `marchine-1.28.1-linux-amd64.tar.gz` and `marchine-1.28.1-linux-amd64.tar.gz.sha256` from the [GitHub release](https://github.com/Magik23/Marchine/releases/tag/v1.28.1), verify the checksum, and follow the [README installation instructions](https://github.com/Magik23/Marchine#prebuilt-linux-release).

The release archive contains the executable and icons but does not automatically create a desktop entry. The optional Foot-based source installer handles that integration, preserving an existing `~/.config/marchine/config.toml`.

**Game Machinery. Browse. Select. Launch.**
