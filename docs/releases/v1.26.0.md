# Marchine v1.26.0 — ARCADE + GAMES, Ready to Launch

**Game Machinery.** Marchine remains a restrained, terminal-native, MAME-first Linux launcher. This release completes the **in-app GAMES management workflow** and refines the controls, editing and packaging around the original two-source design.

## Highlights

### GAMES — Add, Edit and Remove Inside Marchine

- Open **Setup (`S`) → GAMES** to **ADD GAME**, **EDIT GAME** or **REMOVE GAME**. ARCADE remains first in Setup and the source bar.
- Configure a **Name**, **Executable**, optional **Arguments** and optional **Working Directory**. Native Linux games and scripts can launch directly; other commands and compatibility runners such as Wine can be configured when installed.
- Quoted argument paths with spaces are supported. Arguments are handed directly to the chosen process, without Marchine interpreting shell syntax.
- Saved entries appear in GAMES immediately and persist to `config.toml`. No rescan or restart is required. Existing entries can be selected and edited; removing one requires Y/N confirmation and **never deletes the underlying file**.
- The generic GAMES launch engine already existed in v1.25.0 through manual TOML configuration. **v1.26.0 adds the missing complete, user-facing management workflow.**

### Setup — Clear Save and Refresh Actions

- Setup groups **ARCADE first, GAMES second**, with concise instructions for each.
- **Ctrl+S** saves Arcade configuration; **R** refreshes the Arcade index **without saving unsaved fields**. Saving a GAMES entry refreshes that list automatically, so `R` doesn't apply to GAMES.
- Removed redundant metadata text from the Categories header and simplified game-removal confirmation.

### Editors — Paste, Save and Quit Without Surprises

- **Ctrl+Shift+V** pastes executable paths and other text into active fields in Foot.
- **Ctrl+S** now saves the active field immediately, with no extra Enter press. Enter still applies a field and advances; invalid quoted arguments remain editable for correction.
- **Ctrl+C** no longer exits Marchine. **Q** and the existing controller quit chord remain available.

### Controller Font Zoom — Comfortable on Gamepads and Fightsticks

- **Hold View + tap X** to increase font size; **hold View + tap A** to decrease it.
- Standalone X, A and View actions remain intact. View + RB rotation and View + Menu quit remain intact.
- On a **focused Marchine Foot desktop window under Hyprland**, these shortcuts send Foot its existing zoom keys through `hyprctl`; they do not change global Foot settings. Keyboard `Ctrl++` / `Ctrl+-` / `Ctrl+0` zoom continues to work.
- No font or window-size preference is stored. Marchine's desktop launcher still starts fullscreen; Hyprland manages window sizing and positioning afterward.
- When a terminal is below **124×48 cells**, a more helpful warning suggests enlarging the window or reducing the font. Controller font reduction remains usable on supported setups.

### Presentation and Linux Packaging

- The Info source bar shows a compact running release version. Full Git/build information remains available using `marchine --version`.
- Reduced Categories/Setup visual clutter and updated the on-screen keyboard/controller help.
- The source installer now installs **128, 256 and 512 px desktop icons** into user-local hicolor directories; release archives now **include all three icon sizes** for manual installation.
- Expanded regression tests for GAMES persistence, argument parsing, Setup refresh behavior, editing, controller chords and small-window recovery.

## Existing Optional Display Rotation

**Optional feature — Requires [Hypr Rotate](https://github.com/Magik23/hypr-rotate) to be installed.**

The existing **View + RB** chord, introduced before this release, continues to invoke Hypr Rotate for runtime-only display rotation under Hyprland. Marchine doesn't bundle Hypr Rotate, and normal launching works without it.

**[Get Hypr Rotate →](https://github.com/Magik23/hypr-rotate)**

## Download and Requirements

- Prebuilt **Linux amd64** archive with SHA-256 checksum, bundled notices/licenses and desktop icon assets.
- A Unicode-capable terminal is required. **MAME is only required for the automatic ARCADE source**, not for GAMES.
- The optional **Foot desktop launcher** is installed by the source installer when Foot is available. Controller font zoom currently targets that focused Foot window on Hyprland; keyboard font zoom remains terminal-dependent.
- For installation, building from source, and details about the archive directory layout, see the [README](https://github.com/Magik23/Marchine#readme).
