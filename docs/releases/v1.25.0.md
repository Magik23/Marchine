Marchine v1.25.0 brings smoother Arcade browsing, smarter
filtering, refined controller navigation, and optional
display rotation.

### Highlights

**Live Game Counts**
- The source bar now displays the current game count.
- Counts update dynamically with categories, search, source
  selection, and Hide Non-Arcade filtering.

**Improved Arcade Scrolling**
- More consistent selection positioning during long lists.
- Keeps upcoming games visible while navigating.

**Smarter Selection Recovery**
- Preserves the selected game whenever possible.
- If filtering hides it, selects the next visible game,
  falling back to the previous one when necessary.
- No unnecessary jumps back to the top of the list.

**Better Filtering**
- Preserve the selected Arcade category when toggling
  Hide Non-Arcade.
- Update the displayed games and counts in place.

**VERTICAL Arcade Category**
- Browse vertically oriented Arcade games using MAME
  display-orientation metadata.

**Refined Controller Navigation**
- Left / Right: Browse letters.
- View: Switch Arcade / Games.
- Menu: Open Credits.
- LB: Toggle Hide Non-Arcade.
- RB: Cycle themes.
- View + Menu: Quit.
- Setup and Refresh remain keyboard-only.

**MAME Rotation Improvements**
- Marchine no longer injects automatic -autorol arguments.
- MAME and the desktop compositor remain responsible
  for display presentation.

### Additional Improvements

- Named theme labels and improved Info quick settings.
- Updated keyboard and controller shortcut legends.
- Fixed keyboard letter-jump confirmation and cancellation.
- Restored the Marchine icon in the locally installed
  desktop launcher.

---

### Controller Display Rotation — Powered by Hypr Rotate

Press **View + RB** to rotate your display directly from
Marchine when Hypr Rotate is installed.

**[Hypr Rotate](https://github.com/Magik23/hypr-rotate)**
is an independent, lightweight Hyprland utility for
runtime-only display rotation.

The integration is entirely optional. Marchine does not
install or require Hypr Rotate, and normal game launching
remains unaffected without it.

**[Get Hypr Rotate →](https://github.com/Magik23/hypr-rotate)**
