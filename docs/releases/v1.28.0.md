# Marchine v1.28.0 — Your Games, Your Playlists

**Game Machinery.** Marchine now has three simple, complementary sources: **ARCADE** for MAME ROMs, **GAMES** for locally configured launch targets, and **PLAYLISTS** for collections that bring both together in one playable view.

## Highlights

### Mixed playlists, one place to play

- Switch to **PLAYLISTS** (`Tab` or controller View), press **`N`** to name a new collection, and open it with Enter / A. Rename with `R`; delete with `D` followed by explicit **keyboard `Y`**.
- In **ARCADE** or **GAMES**, highlight a title and press **`P`** / controller **View + Y** to save it to an **existing** playlist. Marchine leaves you in the original library, ready to add another title. Saving twice to the same playlist does not create duplicates.
- Open a collection in PLAYLISTS to browse, search and launch both MAME titles and configured executables together, in the order you added them. Press Esc / B to return to the playlist manager.
- Remove a reference with `D` and **keyboard `Y`** inside an opened collection. Removing a reference or deleting a playlist **never deletes ROMs, executable files, desktop shortcuts or GAMES entries**. Missing source games stay visible as `[UNAVAILABLE]` and cannot launch the wrong title.

### Stable game references and compatible upgrades

- Configured GAMES entries now receive permanent IDs, so editing, removing or reordering other entries cannot silently redirect saved playlist references.
- Existing v1.27-era GAMES entries **do not need to be reimported**. Marchine assigns missing IDs in memory on load and writes them alongside playlist information at the next successful configuration save—not merely when the launcher starts.
- Config saves are atomic. They may reformat TOML comments/layout when writing the file; if you maintain a hand-edited config or plan to downgrade to an older Marchine release, **back up `~/.config/marchine/config.toml` first**. Older releases may not preserve the new metadata on save.

### Clearer interface, same focused launcher

- PLAYLISTS joins ARCADE and GAMES in the source bar. Counts, singular/plural labels, frame geometry and context-sensitive footer hints have been aligned across views.
- At the PLAYLISTS root, Esc / B no longer unexpectedly switches to ARCADE. Use Tab / View to change sources; Esc / B remains Back within a collection or dialog.
- INFO now gives a short **SOURCES** explanation and points to the [README](https://github.com/Magik23/Marchine#readme) for the detailed guide, rather than duplicating a long tutorial.
- On supported Hyprland/Foot sessions, a focused-window-only cursor timeout helps the pointer recover cleanly around monitor rotation. Marchine restores the previous runtime setting after it loses focus, launches a game or exits; it does not write compositor configuration. Optional [Hypr Rotate](https://github.com/Magik23/hypr-rotate) remains a separate utility.

## Install / Update

Download this release's **Linux amd64** archive, `marchine-1.28.0-linux-amd64.tar.gz`, and its matching `.sha256` from GitHub Releases. Verify the checksum before extracting and installing; see the [README](https://github.com/Magik23/Marchine#readme) for commands, icons, terminal requirements and source-build options. The binary archive includes icons but does not automatically install a desktop entry; the source installer handles the optional Foot desktop shortcut.

If you already have a Marchine config, consider making a copy before upgrading:

```bash
cp -p ~/.config/marchine/config.toml ~/.config/marchine/config.toml.pre-1.28.0
```

The source installer preserves an existing configuration. Your MAME ROMs and game files are not copied or altered by Marchine playlists.

## Notes

- **ARCADE remains MAME-only** for automatic ROM indexing. Other local programs, scripts and emulator commands belong in GAMES; PLAYLISTS unifies items from those two sources.
- Playlist naming and renaming use keyboard text; destructive playlist confirmations require **physical keyboard `Y`**. The navigation, save picker and launching support normal controller controls, but there is no controller-based naming keyboard.
- Playlists save references locally in TOML; Marchine does not download, install or relocate games.
- This release extends v1.27.0's GAMES import functionality; it does not change Marchine into an online library service or add another automatic emulator driver.
