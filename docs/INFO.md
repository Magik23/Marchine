# Marchine Info + Credits — V1.20

Marchine keeps operational help and project credits separate, with single-key access.

## Info — `I`

INFO contains:

- **HOW IT WORKS** — what GAMES and ARCADE are, and how process handoff works;
- **EMULATOR MODEL** — why the UI says Emulator Executable while the current automatic Arcade driver is MAME;
- **SHORTCUTS** — complete keyboard reference, including `R` for **Refresh Arcade Library**;
- **ARCADE FILTER** — `H` toggles **HIDE NON-ARCADE [ON/OFF]**.

When Hide Non-Arcade is ON, Marchine keeps the complete index in memory but removes non-arcade entries from the visible Arcade playlist and hides `ALL`, casino/gambling, mahjong, `NON - ARCADE`, and other all-non-arcade families from CATEGORIES. Turn it OFF to expose the complete indexed runnable library again.

On wide terminals the SHORTCUTS/ARCADE FILTER column is deliberately pushed farther right so the two INFO columns do not crowd each other.

## Credits — `O`

CREDITS contains authorship, stack, license, local-first philosophy, and the supplied static MARCHINE / Game Machinery BBS-style ASCII identity.

On wide layouts the written credits stay on the left and the BBS artwork is top-aligned on the right. The artwork remains at native terminal-cell geometry and is never resampled or animated.
